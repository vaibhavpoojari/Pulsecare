## 🌟 Overview

**PulseCare AI** is an end-to-end, production-ready healthcare management platform designed for Patients, Healthcare Providers (Doctors), and Pharmacists. Built using modern React 19, Vite, Tailwind CSS, Framer Motion, and Node.js, the system combines real-time data flow with artificial intelligence to optimize clinical workflows and patient care.

---

## ✨ Features

- 🤖 **AI Health Assistant**: Interactive symptom analysis, smart triage recommendations, and patient advice.
- 💊 **Medication Reminders**: Interactive daily dosage tracker, check-off status, and automated refill alerts.
- 📅 **Smart Appointment System**: Real-time doctor booking, status updates, and schedule management.
- 📊 **Dynamic Dashboards**: Dedicated tailored portals for Patients, Doctors, and Pharmacists with analytics cards & vitals tracking.
- 📍 **Interactive Hospital Directions**: Location integration with Dr TMA Pai Hospital (Udupi) featuring Google Maps directions.
- 📄 **Health Reports & PDF Export**: Instant medical summary generation and PDF download using client-side engines.
- 🌙 **Dark Mode & Glassmorphism Design System**: Sleek, modern responsive UI with soft backdrop blurs and fluid micro-animations.

---

## 🚀 Tech Stack

- **Frontend**: React 19, React Router v7, Tailwind CSS v4, Framer Motion, Chart.js, Lucide Icons
- **State & Context**: AuthContext, ThemeContext, AppointmentContext, MessageContext, OfflineContext
- **Backend**: Node.js, Express.js, Firebase Auth & Firestore / MongoDB support
- **Export & Tools**: jsPDF, html2pdf.js, Vite 7, PWA Service Worker
