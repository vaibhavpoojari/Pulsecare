# Contributing to PulseCare AI

Thank you for your interest in contributing to **PulseCare AI**.

PulseCare AI is an AI-powered healthcare management platform designed to improve healthcare services for **Patients, Doctors, and Pharmacists**. We welcome contributions that improve functionality, fix bugs, enhance documentation, or introduce new features.

---

# 🚀 Quick Start

1. Fork this repository.

2. Clone your fork.

```bash
git clone https://github.com/vaibhavpoojari/Pulsecare-AI.git
```

3. Navigate to the project directory.

```bash
cd Pulsecare-AI
```

4. Install dependencies.

```bash
npm install
```

5. Start the frontend.

```bash
npm run dev
```

6. Start the backend.

```bash
cd backend
npm start
```

7. Create a new branch.

```bash
git checkout -b feature/your-feature-name
```

# 🛠 Development Setup

## Prerequisites

- Node.js 18 or later
- MongoDB
- Firebase Project
- Git

---

## Environment Variables

Create the following environment files before running the project.

### Frontend (.env)

```env
VITE_API_URL=YOUR_BACKEND_URL

VITE_FIREBASE_API_KEY=YOUR_API_KEY

VITE_FIREBASE_AUTH_DOMAIN=YOUR_AUTH_DOMAIN

VITE_FIREBASE_PROJECT_ID=YOUR_PROJECT_ID

VITE_FIREBASE_STORAGE_BUCKET=YOUR_STORAGE_BUCKET

VITE_FIREBASE_MESSAGING_SENDER_ID=YOUR_SENDER_ID

VITE_FIREBASE_APP_ID=YOUR_APP_ID
```

### Backend (config.env)

```env
PORT=5000

MONGO_URI=YOUR_MONGODB_URI

JWT_SECRET=YOUR_SECRET
```

# 🤝 Pull Request Guidelines

1. Fork the repository.

2. Create a feature branch.

```bash
git checkout -b feature/feature-name
```

3. Commit your changes.

```bash
git commit -m "Add: Short description"
```

4. Push your branch.

```bash
git push origin feature/feature-name
```

5. Open a Pull Request.

---

# 📌 Code Guidelines

- Follow the existing project structure.
- Write clean and readable code.
- Test your changes before submitting.
- Keep commit messages meaningful.
- Update documentation whenever required.
